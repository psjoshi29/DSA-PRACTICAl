## 🚀 How to Run

### C++ Programs

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal in the project directory.
4. Compile and run a program:

```bash
g++ 01_linear_search.cpp -o practical
```

```bash
./practical
```

On Windows, run the compiled program using:

```bash
.\practical.exe
```

### Python Programs

Run any Python program using:

```bash
python 09bst_traversal.py
```

Replace the filename with the program you want to execute.
